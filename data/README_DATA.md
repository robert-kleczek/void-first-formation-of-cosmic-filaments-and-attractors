# Processed Data Files

- `void_lensing_model_comparison.csv` - locked/topological-gain amplitude comparison and BIC values.
- `filament_orientation_rigorous_stats.json` - block-bootstrap orientation statistics.
- `orientation_score_deciles.csv` - mean filament radial-axis statistic by shell-score decile.
- `refined_velocity_dynamics_summary.json` - Carrick, SDSS PV and Cosmicflows-4 refined velocity summary.
- `carrick_l012_shell_profile.csv` - per-void fitted l=0, l=1 and l=2 shell-mode profile values.
- `bayesian_proxy_summary.csv` - BIC/Bayes-factor proxy calculations used in the manuscript.

These are processed analysis products. Raw catalogues should be retrieved from the source URLs listed in `../DATA_SOURCES.md`.
